# Vision

Build an AI-powered Student Analytics Platform that helps students and
mentors monitor technical growth using:

-   GitHub
-   LeetCode
-   HackerRank
-   Kaggle

The platform should provide meaningful analytics, visualizations,
historical tracking, goal tracking, and AI-powered recommendations.

# Known Constraints

-   Keep the codebase simple.
-   Avoid unnecessary files.
-   Build incrementally.
-   One meaningful phase at a time.
-   Store snapshots only when changes occur.
-   Cache AI summaries to reduce token usage.
-   Gracefully handle unavailable platforms or missing profiles.
